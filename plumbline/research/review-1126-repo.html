0How to read this page

This page uses one word for one thing. A part is a folder or a function of the repo. A test is a Rust test. A demonstration is a script in plumbline/demos/ that operates the real program and checks the result. The window is the program with its two windows. The command line is the program plumbline.

WORKS
All tests and all demonstrations of the part pass.
PARTIAL
The part does some of its functions. Other functions are not built or are not proven.
STUB
The documents name the function. No code does the function.
BROKEN
A check of the part fails today.
CHECKED
I ran a command today and read the output.
INFERRED
I took the item from a record or from an older run. I did not run it today.

6How you verify it

A. In a browser. No installation.

  1. Open the branch claude/hopeful-cannon-kng8eo on GitHub.
  2. Open plumbline/STATUS.md. Find the table of the 13 items. Each item must name a commit, a command, and its output.
  3. Open plumbline/demos/captured/. Each folder has the pictures of one window demonstration. Look at the pictures. If you do not see the thing, the thing is not there.
  4. Open plumbline/research/. Each judgment is a file. A judge writes what it tried and what broke.
  5. Make sure that the tag is on the same commit that STATUS.md names.

B. From a clone. The commands and the results to expect.

git clone -b claude/hopeful-cannon-kng8eo https://github.com/Bitumenmachina/roofnerd
cd roofnerd/plumbline

# 1. The tests. Each "test result" line must say "ok". No line must say FAILED.
cargo test --workspace

# 2. The three gates, from the repo root. Each must end with exit status 0.
(cd .. && tools/gate-language.sh && tools/gate-egress.sh && tools/gate-clientdata.sh --all)

# 3. The licences of all linked crates. Must end with exit status 0.
tools/licenses.sh

# 4. The last commit builds and passes from its own contents.
tools/committed.sh                      # the last line must start with "committed: PASS"

# 5. The sample house. The file must be the same on each machine.
cargo run -p plumbline -- sixteen /tmp/h.json
sha256sum /tmp/h.json                   # must start with 880d9fd3c364b5f7
cargo run -p plumbline -- estimate /tmp/h.json   # last line: the sixteen divisions  $393,981.66
cargo run -p plumbline -- vif /tmp/h.json        # 85 questions, the largest dollars first
cargo run -p plumbline -- clashes /tmp/h.json    # 11: 5 findings, 6 to verify in the field

# 6. Each command-line demonstration. Each must end with exit status 0 and must not print FAIL.
for d in demos/*.sh; do
  case $d in demos/window.sh|demos/field-job.sh) continue;; esac          # two helpers
  grep -q 'plumbline-app\|open_window\|xdotool\|xvfb' "$d" && continue      # window demonstrations
  bash "$d" >/tmp/$(basename $d).log 2>&1 || echo "FAILED $d"
done

# 7. The window. Two windows open: the model and the estimate.
cargo run -p plumbline-app -- /tmp/h.json

# 8. One window demonstration. Its pictures go to demos/captured/price.
xvfb-run -a -s "-screen 0 2500x980x24" demos/pricew.sh

# 9. The BIM file. IfcOpenShell is an outside checker. It is not linked.
cargo run -p plumbline -- export ifc /tmp/h.json /tmp/h.ifc
python3 tools/ifc-check.py /tmp/h.ifc

Step 4 uses much disk space. Keep 15 GB free. The check tools/portmap.sh needs the BIMCraft source on the same machine. It is not in the list for that reason.
