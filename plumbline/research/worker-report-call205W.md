## Before any code (Part 1)

1. How the window gets an item's blocks today, and what it will call.
   Today: the model's `Placement.form: Option<forms::Form>` (building.rs 3334-3338: `forms::drawn_as(said).ok().flatten()`, else
   `forms::form_of(name)`); `scene.rs` ~1230 `match p.form { Some(form) => forms::blocks(form, size) }`, and `bench::placement` does the same for the bench.
   `forms::blocks` is `starter_blocks` over the thirteen. A job's own shape name is not a `Form`, so `drawn_as` is an error, `.ok()` makes it None,
   and the window draws the plain box. What it will call: `building::shape::find(&job.shapes, name)` for the shape (the job's own first) and
   the model's `Shape::worked(size) -> Result<Vec<Block>, String>` for its blocks at the thing's size (the same function `starter_blocks` runs).
   The window works no block out: `model::refresh` (which holds the job) makes a map placement path -> blocks (and the bench item's), and the scene draws what the map holds.
2. "Drawn as" today: `panels.rs` `item_bench`, a fixed list: "What its name says", "Box", then `Form::ALL` (thirteen). It will list the same and, FIRST,
   a row for each of `job.shapes` marked "the job's own" (the shape the item has is marked "as it is now"). Picking is `editing::item_drawn_as`, which already accepts a job's shape (`check_drawn_as`).
3. How a row is typed today: a row is clicked (`on_click`), `doc.open(Entry::X, current text)` opens one field with the hint under it (`entry_box`,
   `entry_words`), Enter calls the handler in `main.rs` by Entry; a refusal is `tools::cant(doc, "...", why)` ("Can't use that size: ...") and the job is as it was
   (`item_size` -> `ed::item_size`). A figure of a block will be a new `Entry::ShapeBlock` opened the same way from a row, handled by `shape_block_set`, refused by `cant` with the model's words
   (and the field opened again on what was typed, as Rename does, so it can be put right).
