# AEC tools notes (started 2026-11-25)
## A Revit (autodesk.com 403 to fetch; via search snippets)
- Price: Revit $3,005/yr, $380/mo, $9,020/3yr (https://www.autodesk.com/solutions/revit-subscription-faq); subscription only. LT: no Autodesk price rendered; resellers ~$606-715/yr (cdw.com) unverified.
- Connectors: placed on faces/workplanes in family editor; flow direction arrows; one primary per discipline; params Flow Factor, Angle, Width/Radius (https://help.autodesk.com/cloudhelp/2016/ENU/Revit-Model/files/GUID-3DE410FC-7BB7-44FD-B75E-A02C4F42C1AD.htm ; 2024 https://help.autodesk.com/cloudhelp/2024/ENU/Revit-Customize/files/GUID-F9FCBE97-55AE-4263-8AF7-6D6F8EA68B6A.htm). No Yes/No param on connectors (https://forums.autodesk.com/t5/revit-ideas/mep-connector-visibility-yes-no/idi-p/6496058)
- Phases: filters New / Existing / Demolished / Temporary; default "Show New", "Show Previous+Demo" etc. (https://help.autodesk.com/cloudhelp/2023/ENU/RevitLT-DocumentPresent/files/GUID-DB104358-4D5A-494E-ACAE-BB8B4E72E572.htm). Forum: demolition is not a phase, filters are view-relative.
- Clash: Interference Check in-model, not issue-managed; Navisworks Clash Detective; ACC Model Coordination; BCF export (https://novedge.com/blogs/design-news/revit-tip-revit-interference-check-to-navisworks-clash-detective-workflow ; https://www.autodesk.com/products/navisworks). 2026 AU class says ACC being rebranded Autodesk Forma.
- Residential: Revit seen as overhead for small jobs (vendor-biased: https://www.snaptrude.com/blog/best-residential-architecture-software-2026 ; https://higharc.com/blog/revit-vs-higharc-a-bim-experts-take-on-the-changing-landscape-of-homebuilding-technology ; https://revizto.com/en/chief-architect-vs-revit)
## B Bluebeam pricing (https://www.bluebeam.com/pricing) per user/yr: Basics $260, Core $330, Complete $440, Max $590 intro. All: Revu Windows + web + mobile. Basics: length/area only. Core: perimeter/count/angle/volume, overlay compare, Studio host, CAD plugins. Complete: Dynamic Fill, Quantity Link (Excel), markup reports, Batch Link/Slip Sheet, scripting. Max: AI (Smart Review/Overlay), MCP. Some measurement not on Android/mobile.

- ODA: Drawings SDK only for apps owned by current members under signed agreement; tiers ~ $3,000 first yr/ $7,500 Pro (one page only, verify) (https://www.opendesign.com/pricing.md ; https://www.opendesign.com/faq/question/how-can-i-join-open-design-alliance-and-use-your-sdks.md).
