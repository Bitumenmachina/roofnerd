## C. Bevy (bevy.org/news, fetched 2026-11-25)
- Releases: 0.20 (2026-10-08), 0.19 (2026-06-19), 0.18 (2026-01-13; 0.18.1 patch 2026-03-02). https://bevy.org/news/
- 0.20 https://bevy.org/news/bevy-0-20/ : Solari (realtime raytraced GI) now on macOS/Metal, no builtin denoiser there; DLSS-RR via dlss_wgpu; Feathers widgets (color input, scrollable list view, dropdown, lazy menu, scrubbable number input), headless Tab, em/rem units; Pan Orbit Camera (CAD-style nav, needs MeshPickingPlugin); ASTC textures for mobile; mesh shaders not on web; tabs integrate with accessibility.
- 0.19 https://bevy.org/news/bevy-0-19/ : contact shadows, physically based SSR, rect area lights (LTC), parallax-corrected cubemaps, vignette/lens distortion, white-furnace-correct PBR, RenderErrorHandler (device loss/OOM recovery), EditableText (IME, selection, multiline; no undo yet), transform gizmo, AccessibleLabel, parley text, web-task cancellable on WASM.
- 0.18 https://bevy.org/news/bevy-0-18/ : atmosphere affects sunlight colour, ScatteringMedium, PBR fix for too-bright specular, FullscreenMaterial, AutoDirectionalNavigation, Popover/MenuPopup, FreeCamera/PanCamera, 2d/3d/ui feature collections, Easy screenshot/record plugins.
- Pages did not state wgpu version; AA/upscaling not covered in these summaries (not verified further).
- wgpu README https://github.com/gfx-rs/wgpu (v30 per quick links): Vulkan native Win/Linux/Android (MoltenVK on mac/iOS, tier 🌋); Metal first-class mac/iOS; DX12 Windows only (dxc needs dxcompiler.dll >=1.8.2502 else fxc); GL needs GL3.3+ Win / GLES3.0 Linux/Android / ANGLE on mac; WebGPU & WebGL2 in wasm.
- WebGPU browsers https://web.dev/blog/webgpu-supported-major-browsers (dated 2025-11-25; may be a year old): Chrome/Edge 113+ Win(D3D12)/mac/ChromeOS, Linux "in progress"; Firefox 141 Win, 145 ARM Mac (Tahoe); Linux/Android/Intel Mac in progress; Safari macOS/iOS/iPadOS 26; Android Chrome 121+ (Android 12+, Qualcomm/ARM GPUs).

- Sunshine docs https://docs.lizardbyte.dev/projects/sunshine/latest/ : host Debian13+/Fedora43+/Ubuntu22.04+/Win11/macOS14.2+/FreeBSD; Linux capture KMS/DRM, X11, wlroots Wayland, XDG portal, KWin; encoders NVENC, VAAPI, AMF, QuickSync, VideoToolbox, SOFTWARE encoding on all; licence not on page; virtual display not mentioned.

- RustDesk https://rustdesk.com/docs/en/ : client open source, self-hostable OSS server, Pro server paid (price not on page); Win/mac/Linux/iOS/Android/Web; H264/H265 hardware; licence & Wayland not on page.

- Moonlight setup guide https://github.com/moonlight-stream/moonlight-docs/wiki/Setup-Guide : host needs 720p+ display or headless dongle on NVIDIA GPU; fauxput (virtual display for Sunshine on Linux). Touch mapping on iPad not found in docs.
- Tailscale personal plan: 6 free users when signed up with public email (https://tailscale.com/kb/1017/install). Latency numbers: none found yet.
- Moonlight setup https://github.com/moonlight-stream/moonlight-docs/wiki/Setup-Guide : Sunshine any modern AMD/NVIDIA/Intel GPU; Win10/11, macOS experimental, Linux (Debian11/Ubuntu22.04/Fedora38+); clients iOS, Android, Win, mac, Linux, ChromeOS; touch has trackpad mode and direct-touch mode (Android, iOS); no latency figures in docs; relayed (non-direct) Tailscale cannot stream; wants 5GHz wifi, wired host.
